# 第6节证据研究推进计划 V1

日期：2026-08-29

本计划用于约束 Issue #73 / Draft PR #74 的后续研究顺序，避免只复核既有五项机会依据而遗漏云端系统新增证据。全部工作保持 research-only；在完成 MASTER 8.1 正式研究转化审查前，不修改正式交易权限、风险许可、Trial／Confirm、固定金额档、卖出份额或自动交易能力。

## 总目标

不是为第6节继续堆指标，而是建立一个统一、可复核、可动态消费且净复杂度可控的“已验证证据体系”。研究对象分成三类：

1. 现行6.2五项历史机会依据：重新验证、消融、条件化、决定保留/调整/合并/删除；
2. 现行6.4正式研究证据：检查资格、动态当前值、数据owner、PIT、降级、bridge消费和重复；
3. 云端系统新增候选证据：利用当前GitHub持续状态、多行情源、daily_features、CURRENT/snapshot、intraday path、relative strength、融资、股指期货、PCF、海外上下文和节点增量，研究旧离线Excel时代无法可靠验证的新信息。

## 执行顺序

### 阶段A：完成现行6.2五项历史依据再验证【已基本完成】

对象：健康突破、放量修复、整理突破、科技风险偏好改善、连续上涨风险复核。

已完成：完整ETF×交易日PIT baseline、年度/对象稳定性、组件消融、基础条件化增量、科技对象集中度、连续上涨T+1二次判别。

阶段A只允许形成“保留/调整/合并/删除候选结论”，不直接改MASTER。

### 阶段B：6.4全部正式研究证据动态接通矩阵【下一步优先完成】

逐项核对：

`正式资格 → 是否需要当前动态值 → canonical producer → 数据时点/PIT → provider/fallback → READY/DEGRADED语义 → research_execution_summary / decision_context消费 → 是否与其他证据重复`。

特别复核此前已暴露的两类问题：
- IF／IC 5日基差：资格已登记但当前动态值链曾未闭环；
- 宁德时代（300750）超跌反转：历史研究中的静态 current 字段不得冒充最新当前状态。

同时确认不需要动态值的“方法/长期背景类证据”，避免为了形式统一制造无价值producer。

### 阶段C：历史可重建的新候选证据研究【完成B后立即推进】

只使用当时可见且能够客观PIT重建的数据，不伪造云端尚未上线时期的信息。第一批候选按优先级研究：

1. **相对强弱边际变化**：目标ETF相对ETF池中位数、相对对应指数的变化速度，而不仅是静态强弱；检验对T+1/T+3/T+5收益及资本排序是否有增量。
2. **成交参与变化 × 价格结构**：成交额/成交量相对自身20日常态的变化与突破、修复、弱势结构的交互；重点判断“成交参与”是否比旧固定倍数阈值更稳健。
3. **ETF池宽度 × 个体相对反馈**：用正式ETF全集的同期横截面上涨比例/中位收益构造可PIT重建的局部市场宽度，检验“弱市抗跌、强市领涨、弱市补跌”等相对反馈是否增加机会判断价值。不得把它冒充全A股市场宽度。
4. **趋势状态 × 修复质量**：在20日/60日趋势背景下比较低位修复、突破延续、冲高回落等完整收盘可重建结构，判断旧五项信号中真正稳定的核心语义。
5. **融资/股指期货 × ETF自身反馈交互**：不是重新研究融资或IF/IC本身，而是测试它们只有在ETF自身结构同向/背离时是否产生额外增量，避免重复加权。

禁止参数网格寻优；先冻结简单、可解释定义，再做消融和条件化。

### 阶段D：云端原生、历史不可可靠回补的新证据【与C并行积累真实前瞻样本，不伪造历史】

这些是当前云端系统相对早期Excel时代最重要的新研究资产：

1. **日内极值时序**：低点先出现还是高点先出现；区分V型修复、冲高回落、高位震荡和低位弱势。
2. **低点后修复力度 / 高点后回撤**：比较同样日涨跌幅下，真实路径质量是否改变后续收益和持仓风险。
3. **最近10分钟边际承接**：相对前10分钟的成交参与变化，只作为承接/衰减证据，不做机械阈值交易。
4. **节点间证据增量**：上一正式节点→当前节点新增、增强、减弱、失效了什么；研究“变化”是否比静态水平更能提高Trial/Confirm、持仓和资本迁移判断质量。
5. **跨市场传导一致/背离**：外部结构→本地传导→ETF自身反馈。重点研究海外强而A股不跟、海外弱而ETF抗跌等背离是否比单纯海外涨跌更有信息量。
6. **对象级产业链证据与ETF反馈交互**：例如半导体设备ETF（561980）核心成分领先、海外开盘定价残差与561980自身结构/承接是否互相确认或否定；不得把产业链对象变成常驻独立交易信号。

阶段D采用真正的forward sample。没有足够样本前只积累和做描述性审计，不因样本少而创造临时规则。

### 阶段E：证据去重、组合与资本效率验证

对阶段A-D通过初筛的证据统一做：

- 与基础趋势、相对强弱、成交承接的增量比较；
- 同类证据重叠率与条件化增量；
- 对“唯一主候选、金额、持有/降低风险/退出、资金来源/去向”是否真的改变判断；
- 是否只是重复描述价格已经发生的事实；
- 是否提高了事前收益效率，还是只提高解释复杂度。

如果两个证据高度重复，优先保留更早可得、更稳定、更便宜、更容易动态接通的一项；不建立综合总分。

### 阶段F：最终证据矩阵与MASTER重构

最终每项证据只允许进入以下结论之一：

`保留 / 调整 / 合并 / 删除 / 新增`。

然后再起草MASTER第6节+8.1最小充分重构：

- 6.1：稳定机会判断框架；
- 6.2：基础证据语义；
- 6.3：指数、高相关、个股与跨市场边界；
- 6.4：统一“已验证证据目录”，不再区分老历史机会依据与新专项研究证据；
- 8.1：统一研究资格与动态接通合同，明确“资格通过 ≠ 当前值已接通”。

规则重构前必须重新读取latest main并按正式变更协议审查；研究结论本身不自动修改MASTER。

## 当前优先队列

1. 完成6.4正式证据接通矩阵；
2. 启动阶段C-1“相对强弱边际变化”；
3. 启动阶段C-2“成交参与变化×价格结构”；
4. 启动阶段C-3“ETF池宽度×个体反馈”；
5. 完成阶段C-4/5条件化交互；
6. 同步建立阶段D真实前瞻样本登记，不伪造历史；
7. 做阶段E去重与资本效率验证；
8. 形成最终保留/调整/合并/删除/新增矩阵；
9. 最后才起草并审查MASTER第6节+8.1重构。

本计划的目的不是增加研究项目数量，而是防止研究顺序失焦：先把现有正式证据接通，再系统验证云端新增信息，最后只把真正改善当前决策的证据留下。
