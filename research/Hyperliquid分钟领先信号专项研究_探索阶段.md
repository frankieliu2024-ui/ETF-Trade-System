# Hyperliquid隔夜领先信号专项研究（多对象探索阶段）

## 1. 研究问题与边界

本专项研究检验：Hyperliquid在A股前一交易日收盘后至次日开盘前可见的价格与市场状态变化，是否对对应A股对象的次日开盘缺口、开盘后收益和风险方向提供独立、可复核、可实现的信息。

本PR只属于research-only研究链，不写入账户事实、Dashboard、正式决策、研究执行桥或交易权限，不生成订单，不改变通知链。分钟级研究暂不纳入本PR；本阶段先完成隔夜和次日开盘的可靠基线。

## 2. 对象与经济映射

对象必须逐一建立映射，不得把CXMT结论外推给其他对象。当前研究目录分为四类：

|类别|对象|拟检验的A股映射|
|-|-|-|
|直接/产业对象|CXMT、GIGADEV|长鑫科技（688249.SH）及经证据确认的同产业链A股对象；若无唯一对应标的，标记为无直接映射|
|半导体/科技外部驱动|SMH、SOXL、DRAM、NVDA、AMD、SNDK、AVGO、NBIS、COHR|A股半导体、存储、设备、算力/光模块相关ETF或个股；必须明确是直接映射、产业链映射还是主题映射|
|宏观/风险偏好|XYZ100、SP500、EWY、EWJ、EWT、GOLD、COPPER、BRENTOIL、XLE|A股宽基、跨境/区域风险偏好、商品资源或能源相关ETF；仅在经济暴露合理时使用|
|医药/消费与其他|XBI、BABA|A股医药/创新药、港股互联网或相关ETF；不能因名称相似直接认定有效映射|

映射字段至少包括：object_id、hyperliquid_asset、a_share_target、mapping_type、mapping_reason、mapping_confidence、no_mapping_reason。映射置信度不等于信号有效性，二者必须分别结论。

## 3. 统一样本定义

每个对象独立构造样本，不用CXMT样本替代其他对象。每个A股交易日D定义：

- A股前收盘：D-1收盘；
- 隔夜窗口：D-1 A股收盘后至D日A股集合竞价前的最后合法Hyperliquid观测点；
- 主要结果：gap_D = A股D日开盘 / A股D-1收盘 - 1；
- 次要结果：D日开盘至收盘收益、开盘后最大有利/不利变动；
- 外汇调整：对美元计价对象同时保留原始变化与USD/CNH调整后变化；
- 其他状态：成交量、资金费率、溢价、持仓量及变化仅在具有合法PIT时间边界时纳入。

必须记录A股交易日历、各市场时区、观察时点、缺失区间、provider时间戳状态和样本剔除原因。不能把接口返回时间当成事件发生时间；无法确认事件时间时，结论只能降级。

## 4. 统计与稳健性

对每个对象分别报告：

1. 样本数、有效匹配数、缺失和异常日期；
2. 隔夜变化与次日开盘缺口的相关性、方向命中率及简单基准；
3. 控制A股前一日收益后的增量解释力；
4. 分位数组、方向条件和大波动/小波动分层；
5. 开盘后收益的相关性、方向命中率及反转比例；
6. 滚动窗口、前后半样本和留出期结果；
7. 交易成本、价差、滑点、可执行时间和资金费率影响（缺失时明确不能得出净收益结论）。

不得仅以单一相关系数、单一命中率或最佳阈值认定有效。样本不足、映射不唯一、PIT不合格、结果不稳定或无法估算执行成本时，结论为“证据不足”或“待持续采集”，不是“无效”。

## 5. 对象级结论枚举

每个对象必须独立给出以下之一：

- VALID_OPEN_GAP_EVIDENCE：对次日开盘缺口存在稳定且可复核的增量证据；
- OPEN_GAP_ONLY：只支持开盘缺口提示，不支持全天方向或盈利策略；
- INVALID：在合法样本和基准下未显示有用关系；
- INSUFFICIENT_EVIDENCE：样本、映射、PIT、质量或稳健性不足；
- PENDING_CONTINUOUS_COLLECTION：研究设计成立，但当前仍需持续采集验证。

只有在开盘缺口和开盘后可实现收益均有增量信息、且成本审查通过时，才可列为主动收益候选；否则不得把“领先开盘”写成“可直接交易”。

## 6. 当前CXMT结论的定位

现有53个交易日结果支持：xyz:CXMT → 688249.SH在样本内对次日开盘缺口具有较强领先关系，但尚不足以证明全天方向或扣除成本后的稳定盈利。该结论作为本专项的已知基准和待外样本验证对象，不作为其他对象的先验结论。
