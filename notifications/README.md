# 通知事件层

通知层只推送具有独立行动或关注价值的事项，不生成交易权限或自动下单。PushPlus 是高价值信息与用户行动通道，不是 GitHub 运行日志出口。通知状态统一保存在 `data/state/notification_center.json`。

## 一、市场分类

用户可见市场固定为三类：

- **A股市场**：正式A股指数、全部持仓ETF与观察ETF，以及按系统规则参与比较的账户底仓个股。
- **美股市场**：正式指数层继续区分纳斯达克100指数（NDX）、费城半导体指数（SOX）；现金盘路径和扩展时段使用纳指100ETF代理（QQQ）、半导体ETF代理（SOXX）等现有代理，不得混淆。
- **亚太市场**：日经225指数（N225）、韩国综合指数（KOSPI）、台湾加权指数（TWII）、恒生科技指数（HSTECH）。香港不单独形成第四类用户可见市场。

底层继续复用既有A股、overseas、US三条行情链，不新增provider、平行交易规则系统或通知队列。

## 二、通知价值原则

不设置夜间免打扰，也不要求所有市场按固定时点整齐推送。主动通知必须能回答：发生了什么、为什么现在值得知道、对ETF系统意味着什么、用户现在需要做什么。

普通行情波动、普通创新高/新低、普通排名变化、研究更新、维护成功、自动修复成功和例行状态刷新只后台记录。市场类PushPlus分为：

1. **开盘有价值信号**：不逢开必报，只有开盘后出现足以改变注意力排序的方向或结构才推送。
2. **市场有价值事件**：盘中或海外交易时段出现快速重定价、极端波动、方向反转、显著分化时即时推送。
3. **收盘总结**：A股、美股固定保留；亚太主要总结放在日韩台主要市场收盘后、A股尚未收盘的窗口，香港16:00后只在实质改变此前区域判断时追加。

所有阈值仅控制“是否值得占用注意力”，不是 `ETF规则_MASTER.md` 的交易规则，不新增风险许可、生命周期或金额档。

## 三、哪些事件值得主动通知

系统不再把“突然涨跌、极端涨跌”视为全部事件，只把它们视为两种例子。当前保留五个事件族：

### 1. 开盘异常

开盘本身不是事件；明显的开盘方向、跳空或横截面分化才是事件。

- A股：09:35后的连续竞价节点，核心指数绝对涨跌约达到1%、监测ETF约达到2%，或ETF领先与落后差约达到2.5个百分点时，可形成开盘有价值信号。
- 美股：美东09:35后的稳定观察窗口，纳指100ETF代理（QQQ）或半导体ETF代理（SOXX）绝对涨跌约达到1%，或二者分化约达到1个百分点时，可形成开盘有价值信号。
- 亚太：不等待全部市场开盘。日本、韩国、台湾、香港任一当天已开盘对象较前收绝对变化约达到1%，即可先以“亚太市场”名义推送；后续市场若给出相反反馈，应更新区域判断。

### 2. 快速重定价

对应此前口语中的“突然涨跌”。相邻有效行情脉冲在20分钟内绝对变化约达到1%时，属于短时间价格重新定价候选。

它强调**速度**，不是最终全天幅度。离散脉冲不能伪装成完整分钟路径。

### 3. 极端波动

强调**绝对幅度已经进入非常规区间**：

- A股正式指数当日绝对涨跌约≥2.5%；监测ETF约≥4.0%；
- 美股核心代理、亚太正式指数当前有效阶段绝对涨跌约≥2.0%。

极端幅度只要求重新评估，不直接形成买卖动作。

### 4. 方向反转

价格先形成足够大的单向日内幅度，随后大幅回吐或修复，原先“单向强/弱”的解释可能失效。例如核心指数盘中一度较前收上涨约1.5%以上、随后回到接近平盘，或先大跌后明显修复。

A股指数、ETF和具备可靠当日日内OHLC的亚太正式指数可使用这一事件。美股扩展时段与现金盘语义复杂，当前不使用跨时段高低点强行生成反转事件。

### 5. 显著分化

即使没有单个对象极端上涨或下跌，市场内部相对差也可能改变传导判断：

- A股核心指数之间差约≥2个百分点，或监测ETF横截面差约≥4个百分点；
- 纳指100ETF代理（QQQ）与半导体ETF代理（SOXX）差约≥1.5个百分点；
- 当日有效亚太市场之间差约≥2个百分点。

显著分化用于提醒“不能继续用单一市场方向概括全部机会/风险”。

普通放量、普通创新高/低、单纯上涨排名变化不单独成为通知事件；只有它们实质改变相对强弱、风险收益、候选或已有假设时，才通过上述事件或正式交易判断体现。这样避免把PushPlus变成行情播报器。

## 四、防刷屏与升级

同一对象、同一方向的快速重定价采用45分钟冷却。极端波动、方向反转和显著分化在同一市场日、同一对象/结构、同一方向默认只主动通知一次；快速重定价随后升级为极端波动或方向反转，可以追加一次，因为信息含义已经变化。

已经结束交易时段的旧行情不得因workflow重跑重新包装成当前事件。A股异动必须属于当日有效交易/正式close窗口；亚太异动必须来自北京时间当日有效市场日期；美股PRE_MARKET/POST_MARKET必须使用扩展时段相对最近现金盘收盘的变化。

## 五、A股市场

### 开盘

不固定推送。满足开盘有价值信号才发送。集合竞价与连续竞价分开解释。

### 收盘

15:00正式close后固定发送一次A股市场收盘总结，覆盖上证指数（000001）、科创50指数（000688）、创业板指（399006）、ETF横截面领先/靠后对象及日内路径。价格有效时点固定解释为15:00；provider晚于15:00的补查时间必须单列。

A股收盘PushPlus负责即时行情结构；15:30“ETF交易复盘”继续负责账户、风险许可、生命周期、资本效率、持仓/卖出和CASE完整闭环。

## 六、美股市场

美股开盘只在有价值时推送。现金盘收盘固定总结必须包含开盘、高低点、相对前收、相对开盘、低点修复、距高点回撤、区间位置以及首小时/中段/尾段路径，不能只报最终涨跌幅。

盘前/盘后事件使用扩展时段相对最近现金盘收盘的变化，不得把上一现金盘旧涨跌重新包装成当前异动。

所有美股证据继续经过：

`外部结构 → 本地传导 → ETF自身反馈 → 机会判断`

不得直接形成A股ETF买卖动作。

## 七、亚太市场

亚太市场统一覆盖日本、韩国、台湾、香港，但不假定同步开盘或同步收盘。

### 开盘

没有固定推送时间。任何一个当天已开盘市场先出现有价值信号即可先推送，后开市场再用于验证区域共振、削弱或背离。

### 主要市场收盘 / A股尾盘参考

**固定主总结前移到北京时间14:35—14:55。** 日本、韩国约14:30进入收盘结果，台湾更早已经收盘，而A股15:00仍未结束。这个时点比等待香港16:00更有交易价值，因为A股尚有最后约20分钟可用于风险收益和持仓复核。

该总结必须：

- 汇总当日有效的日经225指数（N225）、韩国综合指数（KOSPI）、台湾加权指数（TWII）；
- 将仍在交易的恒生科技指数（HSTECH）明确标记为“盘中”，不得伪装成已收盘；
- 尽量加入当时最新A股指数反馈，说明区域共振或背离；
- 保留每个市场真实provider时点。

### 香港16:00后的更新

不再固定发送第二篇亚太收盘总结。只有恒生科技指数（HSTECH）从14:35主总结后变化约≥1个百分点，或者香港收盘使区域综合判断发生实质变化时，才追加“亚太市场｜香港收盘后更新”。

若14:35主总结因为运行故障缺失，16:00后的节点可作为兜底形成一次总结。香港收盘属于A股15:00之后的新证据，只进入下一A股交易节点，不反向改写当天A股正式事实。

恒生科技指数（HSTECH）的结构变化还应直接复核恒生科技ETF（513180）的自身反馈。

## 八、统一模板

开盘有价值信号、市场有价值事件和收盘总结统一优先采用：

`发生了什么 → 日内/阶段路径 → 为什么值得现在知道 → 对ETF系统的启示 → 现在怎么做 → 数据时点 → 解释边界`

正式交易机会、账户确认、成交确认和真实系统故障可以保留业务特有栏目，但不得退回只有“状态变化，请重新检查”的低信息量模板。

## 九、执行边界

通知记录继续使用既有生命周期和去重机制。用户确认的真实成交继续通过正式账户事实/成交同步链处理，不从最终持仓反推成交。

通知模块不得修改MASTER、扩大交易权限、创建金额档或自动下单。市场通知负责提高注意力和触发重新评估；真正的交易动作仍严格执行MASTER买入/卖出链。

系统事件、A股市场通知、收盘账户提醒和正式决策重评由 `.github/workflows/decision-notification.yml` 承载；美股市场通知由 `.github/workflows/us-extended-hours-pulse.yml` 承载；亚太市场通知由 `.github/workflows/overseas-preopen-pulse.yml` 承载。
