# 市场行情查询路由与全球时点规则 V1.0

> 定位：本文件只解释ETF系统内部查询路由的工程实现、输入输出和职责边界，不是第五个规范域，不定义市场时段、数据资格、provider优先级、freshness阈值、正式监测对象或交易权限。
>
> 稳定数据规则唯一读取：`ETF与市场监测数据接口使用规范.md`；当前对象、provider顺序和runtime参数读取机器配置与最新状态。本文与数据规范或机器事实冲突时，以数据规范和对应机器权威为准。

## 1. 入口与职责

ETF系统内部无网络行情路由唯一实现：`scripts/market_quote_router.py`。

单对象查询入口：`scripts/query_market_object.py`。

查询时即时补采：`scripts/query_time_market_refresh.py`。

核心职责链：

```text
查询请求 / 当前上下文
→ 对象与市场识别
→ 读取数据规范和runtime配置确定当前市场阶段与资格边界
→ 从已生成状态中选择合格事实
→ 生成路由视图
→ 用户可见层转换为自然中文
```

`market_quote_router`本身不直接请求provider、不修改`CURRENT`、不生成账户事实、不产生交易动作。provider采集、CURRENT生成和海外/扩展时段事实由各自canonical producer负责。

## 2. 输入事实

路由层可以消费的事实包括但不限于：

- `data/state/CURRENT.json`
- `data/state/overseas_context.json`
- `data/state/us_extended_hours_context.json`
- 由正式查询时补采链产生且通过质量门的对象事实
- `config/runtime_policy.json`
- `config/market/provider_priority.json`
- 正式交易日历及对象配置

这些文件分别承担运行事实或配置职责，不因被路由层读取而获得新的规范权威。

## 3. 市场阶段与时点

具体市场阶段定义、交易时段、扩展时段、跨时区解释、Point-in-Time和freshness规则统一读取`ETF与市场监测数据接口使用规范.md`及当前runtime配置；本文不复制第二份时间表。

路由输出必须保留足以审计的：

- 对象和市场；
- provider真实时点；
- 北京时间和必要的市场本地时间；
- 当前市场阶段；
- 数据性质（实时、扩展时段、已收盘参考、上一交易时段参考、代理或降级）；
- 数据质量/降级原因。

不得使用workflow完成时间替代provider时点，也不得把不同市场的非同步数据解释为同一时点共振。

## 4. 查询来源边界

普通聊天中的临时公开行情查询可以由ChatGPT自主选择可靠公开来源；当问题进入ETF系统的正式分析、账户/持仓/观察对象、生命周期、风险许可、金额、卖出或正式研究证据时，必须优先消费ETF系统的当前正式事实和规范边界。

公开Web行情可以作为外部补充或交叉验证，但不得冒充canonical CURRENT、账户事实或正式系统provider输出，也不得绕过系统降级语义直接生成正式交易动作。

用户显式指定某一来源时可以按要求查询，但指定来源不改变正式数据资格和Point-in-Time边界。

## 5. 输出职责

路由层回答“当前可用的市场事实是什么”，不回答“是否买卖”。用户可见输出遵守数据规范的中文业务语言门禁；内部状态码、market phase和provider字段可以保留用于技术审计，但普通正式交易回复不得用机器字段替代业务结论。

`decision_context.json`、`query_context.json`和`review_context.json`中的行情摘要应消费统一路由视图或同一规范语义，不自行维护第二份市场阶段或provider规则。

## 6. 决策边界

正式交易判断仍按：

```text
市场事实
→ 外部结构 / 本地传导
→ ETF自身结构与承接
→ MASTER机会、风险收益和资本比较
→ 交易决策
```

海外、指数、ETF、个股或扩展时段行情均不得绕过MASTER独立产生风险许可、Trial／Confirm、金额、卖出份额或订单。

## 7. 维护原则

- 本文件只随路由职责、输入输出或调用链变化而更新；
- 市场时间表、provider优先级、对象清单和runtime参数变化不应要求同步修改本文；
- 新增provider或市场阶段语义必须先进入数据规范/机器配置所属owner，不能先在本文定义；
- 测试优先验证路由合同和权威归属，不依赖本文具体句子或段落位置。
